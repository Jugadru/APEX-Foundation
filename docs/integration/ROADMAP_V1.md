# Roadmap toward v1.0 (proposal)

Initial ten increments deliver experimental offline infrastructure, not a production-ready ecosystem.

| Increment | Goal | Acceptance |
|---|---|---|
| 0.5.1 | Reconcile source pins and interpreter support | Exact source audit, fresh FAST/Hyper diagnostics, Python 3.10 test |
| 0.6.0 | Read-only Core 2 adapter | Native tests and exact metadata mapping; no sporting authority transfer |
| 0.6.1 | Independent Hyper adapter | Native longitudinal and contract tests |
| 0.7.0 | Native evidence bridge | Reuse Lab producers, exact artifacts and scoped attestations |
| 0.7.1 | Historical data/content pilot | Verified provenance, rights and 2012 consistency |
| 0.8.0 | Configuration and persistence adoption | Native config mapping and SaveGuard cross-revision regression |
| 0.8.1 | Asset interoperability | Exact Blender export, Godot import, visual QA |
| 0.9.0 | Reviewed data-only mod loader | Native threat model, permissions, sandbox and rollback |
| 0.9.1 | Deferred runtime contract reconciliation | Preserve existing bus/command/save/replay authority |
| 1.0.0 | Stable integration release | Exact-SHA consumer tests, owner approval, documented rollback |

Proposed milestones, not approved consumer changes. Prioritize P0 blockers in debt.json. Hyper sporting roadmap and game versioning remain independent.
